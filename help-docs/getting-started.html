Getting Started

Melvec is a video-first library application.

The app is designed primarily for managing, organizing, searching, and processing personal video and associated media collections. Melvec also supports images as companion media so you can keep related visual assets alongside your videos when needed.

While image files are supported, Melvec is not intended to be a dedicated image or photo library application.

  1. Installation: Download the app from the official website or app store(Available after 5th Oct 2026). Run the installer and follow the on-screen instructions.
  2. Launch the App: Open the app from your Applications folder (on macOS).
  3. Initial Setup: On first launch, you'll be prompted to select a default folder for your video library or import existing videos.
  4. Interface Overview: The main window includes a sidebar for folders/tags, a central video list, and a preview pane.

Tip: Use the menu bar to access additional features like importing videos or settings.
