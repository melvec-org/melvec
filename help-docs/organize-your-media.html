Organizing Your Media

How to make a large local library actually usable

Folders alone become hard to navigate once a collection grows. Melvec gives you several lightweight ways to add meaning on top of the files without moving them.

Titles

You can give any video or image a custom title. This is often more useful than the original filename, especially when the file came from a camera, phone or download with a cryptic name.

Tags

Tags let you group media by any attribute that matters to you — genre, person, project, location, mood, technical notes, etc. A single item can have multiple tags, and the same tag can be used across different collections.

Playlists

Playlists are ordered lists of videos. They are useful for:

  • Project assemblies or rough cuts
  • Reference sets you return to often
  • Teaching sequences or research collections
  • Personal viewing lists

You can add or remove items from a playlist at any time without affecting the original files.

Star ratings & quality notes

Mark items with a star rating so your favourites surface quickly. You can also note technical quality if that helps you later when choosing footage.

Collections

Collections map to the actual folders inside your library root. Melvec creates them automatically during the scan. Deeply nested folders are flattened and organised by year so the list stays readable.

You can rename collections in Settings → Collections. Renaming a collection does not move or rename the underlying folders on disk.

Multiple libraries

You are not limited to a single library root. You can create additional libraries (for example one for personal footage, one for work projects, one for archival material) and switch between them whenever you need.

Companion images that sit next to videos in the same folder are kept together in the same collection so related stills and clips stay easy to find.

More detail and workflow examples are on melvec.org.
