Trouble Shooting

  • App Won't Launch: Ensure your macOS is up to date. Try restarting your computer or reinstalling the app.
  • Video Won't Play: Check if the file is corrupted or if codecs are missing. Install VLC for external playback if needed.
  • Search Not Working: Reindex your library via Settings > Reindex Library.
  • Performance Issues: Close other apps or reduce the number of videos loaded at once. Ensure you meet system requirements.
  • Error Messages: Note the error code and search our support forum or contact hello@melvec.org

If issues persist, reset the app via Settings > Reset to Defaults (this won't delete your videos).
