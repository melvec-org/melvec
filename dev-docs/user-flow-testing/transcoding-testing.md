## Video Tools / Transcoding

### 1. Optimize a video file

- Open the video tools/utilities section.
- Choose **Optimize Video**.
- Select a video and start the operation.
- Verify the output file is created successfully.

### 2. Resize a video

- Open the video tools section.
- Choose **Resize Video**.
- Set the target size.
- Start the process.
- Verify the resized output is created.

### 3. Convert a video format

- Open the video tools section.
- Choose **Format Conversion**.
- Select input and output format.
- Start the conversion.
- Verify the converted file is created.

### 4. Stop a running video-processing task

- Start optimize/resize/convert.
- Click **Stop** while it is running.
- Verify the process stops cleanly.
