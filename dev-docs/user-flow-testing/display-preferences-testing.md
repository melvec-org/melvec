## Display preferences

### 1. Change an application setting and verify it works

- Open **Settings**.
- Change any available setting.
- Save it if needed.
- Verify the UI or behavior changes accordingly.

### 2. Change a user preference and confirm it persists

- Open **Preferences**.
- Update a preference.
- Close and reopen the app.
- Verify the preference remains applied.

### 3. Change the app theme

- Go to settings/preferences.
- Select a different theme.
- Verify the UI updates immediately.

### 4. Control hidden collection visibility

- Open preferences.
- Toggle the hidden collections option.
- Verify hidden collections appear or disappear accordingly.
