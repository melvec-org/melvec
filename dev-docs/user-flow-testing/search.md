## Search

### 1. Find a video by title or keyword

- Use the main search bar.
- Enter a title or keyword.
- Submit the search.
- Verify relevant results are displayed.

### 2. Search and then reopen previous searches

- Perform several searches.
- Open search history.
- Verify previous searches are listed.

### 3. Remove a search term you no longer want saved

- Open search history.
- Delete one item.
- Verify it disappears.

### 4. Clear all search history

- Open search history.
- Click **Clear All**.
- Confirm the action.
- Verify the history list is empty.

### 5. Verify updated media can still be found

- Rename or move a media item.
- Search for it again.
- Verify it still appears correctly after indexing/update.

### 6. Verify Search can be done on any spell error

- Type a word with wrong spelling ( more than 4 letters long)
- You should see search results ( quick )
