## Collections

### 1. Organize a video into the correct collection

- From the video library, open any video.
- Click the video to open the **video details panel**.
- In the **collection information** section, select a different collection.
- Save or confirm the change.
- Verify the video now appears in the new collection and no longer appears in the old one.

### 2. Organize an image into the correct collection

- Open a collection that contains images.
- Click an image to open the **image details panel**.
- In the **collection information** section, choose a different collection.
- Confirm the action.
- Verify the image is moved to the new collection.

### 3. Create a new collection when media does not fit an existing one

- Go to the **Collections** section.
- Click the **Add Collection** or **+** action.
- Enter the collection details such as year and label.
- Save the collection.
- Verify the new collection appears in the collections list.

### 4. Rename a collection to improve organization

- Go to the **Collections** section.
- Locate the collection to rename.
- Open the collection action menu or context menu.
- Click **Rename**.
- Enter the new name and save.
- Verify the new collection name is shown everywhere in the UI.

### 5. Hide a collection to reduce clutter

- Go to the collections list.
- Open the action menu for a collection.
- Click **Hide Collection**.
- Verify it no longer appears in the normal collection list when hidden collections are turned off.

### 6. Show hidden collections again when needed

- Open application preferences/settings.
- Enable hidden collection visibility if required.
- Find the hidden collection.
- Use the collection action menu and click **Unhide Collection**.
- Verify it is visible again in normal browsing.

### 7. Review everything inside a collection

- Open the **Collections** section.
- Click any collection.
- Verify all videos and images inside the collection load correctly.
- Open a few items to confirm details load properly.

### 8. Work with media from an external watch folder

- Go to a watch-folder-based collection.
- Open the collection.
- Verify external media items are shown.
- Open one of the items and confirm its details panel works.
