## Tags

### 1. Create a new tag for easier grouping

- Open a video or relevant tag-editing flow.
- In the tag editor, type a new tag name.
- Choose **Create New Tag**.
- Save/apply it.
- Verify the tag is created and attached.

### 2. Add an existing tag to a video

- Open the tag editor for a video.
- Search for an existing tag.
- Select it.
- Verify it is attached to the video.

### 3. Remove a tag from a video

- Open the tag editor on a video.
- Click the remove icon on a tag chip.
- Verify the tag is removed from the video.

### 4. Browse all items under a tag

- Go to the **Tags** section.
- Click a tag.
- Verify all linked videos/items are displayed.

### 5. Rename a tag to keep labeling clean

- Go to the **Tags** area.
- Select a tag.
- Use the rename action.
- Enter the new name and save.
- Verify the new label is shown.

### 6. Delete a tag that is no longer useful

- Open the tags section.
- Locate a tag.
- Use the delete/remove action.
- Confirm deletion.
- Verify it no longer appears.
