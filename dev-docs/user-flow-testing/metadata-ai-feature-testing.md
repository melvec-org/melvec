## Metadata / AI Features

### 1. Generate a description for a video

- Open a video details or metadata panel.
- Click **Generate Description**.
- Wait for the process to finish.
- Verify a description is added.

### 2. Stop description generation if it was started by mistake

- Start generating a description.
- Click **Stop** before completion.
- Verify the process stops.

### 3. Add or edit a description manually

- Open the video metadata/details area.
- Type or edit the description field.
- Save it.
- Verify the description persists.

### 4. Generate a transcript for a video

- Open a video’s metadata tools.
- Click **Generate Transcript**.
- Wait for the result.
- Verify transcript text is produced.

### 5. Run metadata generation for multiple videos

- Select multiple videos if the UI supports it.
- Start batch description generation.
- Verify the process starts for all selected videos.
