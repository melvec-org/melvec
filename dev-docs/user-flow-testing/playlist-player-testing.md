## Playback and Playlist Consumption

### 1. Play a video from a playlist

- Open a playlist.
- Click a video.
- Verify playback starts and the app knows the current playlist context.

### 2. Move to the next item in the current playlist

- Start playing a video from a playlist.
- Use the next button or allow autoplay if enabled.
- Verify the next playlist item plays.

### 3. Go back to the previous item in the playlist

- Start playback from a playlist.
- Use the previous control.
- Verify the previous playlist item opens.

### 4. Change playlist playback behavior

- Open settings/preferences related to playback.
- Turn **autoplay**, **shuffle**, or **repeat** on/off.
- Play videos from a playlist.
- Verify playback follows the selected behavior.

### 5. Check for related video

- Related video should appear for any given video if it has similarity with other collection, title, content, tags, playlists
