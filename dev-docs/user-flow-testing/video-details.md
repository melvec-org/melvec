## Video Details and Media Editing

### 1. Fix a wrong video title

- Open a video from the library.
- In the **video details panel**, edit the title.
- Save the change.
- Verify the updated title appears in the library and details panel.

### 2. Update the source of a video

- Open the video details panel.
- Find the **Source** field.
- Enter/select the correct value.
- Save it.
- Verify the source is updated.

### 3. Update the category of a video

- Open a video’s details panel.
- Find the **Category** field.
- Choose a new category.
- Save the change.
- Verify the category updates correctly.

### 4. Mark a video as NSFW or not NSFW

- Open the video details panel.
- Toggle the NSFW control.
- Save if needed.
- Verify the status changes in the UI.

### 5. Rename the actual media file for better file organization

- Open a video or media item details panel.
- Choose the **Rename File** action.
- Enter a new file name.
- Confirm.
- Verify the renamed item still opens correctly in the library.

### 6. Remove a media item from the library

- Select a media item.
- Use the delete/remove action.
- Confirm the removal.
- Verify the item disappears from the library listing.
