## Image Details

### 1. Fix an image title

- Open an image from a collection.
- Edit the title in the image details panel.
- Save the change.
- Verify the updated title appears correctly.

### 2. Mark an image as NSFW

- Open the image details panel.
- Toggle the NSFW setting.
- Save if needed.
- Verify the UI reflects the new status.

### 3. Reassign an image to the right collection

- Open an image details panel.
- Use the **collection information** field.
- Select another collection.
- Confirm the move.
- Verify the image appears in the new collection.
