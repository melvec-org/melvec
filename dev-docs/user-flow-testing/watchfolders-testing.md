## Watch Folders

### 1. Bring media into the app automatically from a folder

- Go to the **Watch Folders** section.
- Click **Add Watch Folder**.
- Select a folder from your computer.
- Confirm the selection.
- Verify the watch folder appears in the list and its media becomes available.

### 2. Refresh a watch folder after adding files outside the app

- Add new media files into the watched folder using Finder.
- Return to the app.
- Open the **Watch Folders** section.
- Click **Refresh** on that watch folder.
- Verify the new files appear in the related external collection.

### 3. Stop monitoring a folder that is no longer needed

- Open the **Watch Folders** section.
- Find the folder to remove.
- Click **Remove** or **Delete**.
- Confirm the action.
- Verify it is no longer listed.

### 4. Import a video from a watch folder into the main library

- Open the watch-folder collection.
- Click a video to open the details panel.
- Use the **collection information** area to assign it to a library collection.
- Confirm the action.
- Verify the video appears in the selected collection.
