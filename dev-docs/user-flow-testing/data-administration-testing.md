# Data Administration

## Export / Import / Backup

### 1. Export videos out of the app

- Open the export section.
- Choose the videos or export target.
- Click **Start Export**.
- Verify export begins and output is created.

### 2. Pause and resume an export

- Start an export.
- Click **Pause**.
- Verify it pauses.
- Click **Resume**.
- Verify it continues.

### 3. Stop an export that is no longer needed

- Start an export.
- Click **Stop/Cancel**.
- Verify the operation halts.

### 4. Export all metadata as a backup

- Open the metadata export/backup area.
- Click **Export All Metadata**.
- Choose a destination if prompted.
- Verify the backup file is created.

### 5. Restore metadata from a backup

- Open the import/restore area.
- Select a metadata backup file.
- Run the import.
- Verify collections/tags/playlists/metadata are restored as expected.

## Logs, Reports, and Maintenance

### 1. Check logs after performing actions

- Perform a few actions like import, move, rename, or export.
- Open the logs/reporting area.
- Verify entries were recorded.

### 2. Clear logs when troubleshooting is complete

- Open the logs area.
- Click **Clear Logs**.
- Confirm it.
- Verify logs are removed.

### 3. Generate a system report for debugging

- Open the system tools/diagnostics section.
- Click **Get System Report**.
- Verify a report is generated or displayed.

### 4. Clear action history

- Open maintenance or history controls.
- Click **Clear Action History**.
- Confirm the action.
- Verify recent suggestions/history are cleared.

### 5. Reset metadata or settings when starting fresh

- Open system maintenance tools.
- Choose **Reset Metadata** or **Reset Preferences/Settings**.
- Confirm carefully.
- Verify the app returns to a clean/default state.
