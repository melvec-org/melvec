## AI Model Management

### 1. Download AI models required for metadata features

- Open the AI model management section.
- Select the desired model tier.
- Click **Download**.
- Verify the download starts and completes.

### 2. Pause and resume model downloads

- Start a model download.
- Click **Pause**.
- Verify it pauses.
- Click **Resume**.
- Verify it continues.

### 3. Delete model files to free space

- Open AI model management.
- Click **Delete Model Files**.
- Confirm the action.
- Verify the files are removed.

### 4. Verify metadata features depend on model availability

- Try a model-based feature like transcript or description generation.
- Verify it works when models are present.
- Delete models and try again.
- Verify the app handles missing models gracefully.
